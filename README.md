Genshin Server Switcher (原神官B服一键切换器)
这是一个简单的 Windows 批处理脚本（.bat），旨在帮助玩家在不重复下载游戏资源的情况下，快速在**原神官方服（天空岛）**和 **Bilibili 服（世界树）**之间切换。

🛠️ 核心原理
通过修改游戏主目录下的 config.ini 配置文件中的 channel 和 sub_channel 参数，实现客户端身份的快速转换。

🚀 使用方法
1. 环境准备
确保你的电脑上已经安装了任意一个版本的《原神》（官服或B服均可）。

如果你当前的资源是纯官服资源，切换 B 服时需要额外的 plugins 文件夹（包含 B 站 SDK），请自行从 B 站客户端提取并放入 Genshin Impact Game 目录下。

2. 部署脚本
进入游戏的主程序文件夹，路径通常为：
...\Genshin Impact Game\ (即包含 YuanShen.exe 的文件夹)。

将本仓库中的 Switcher.bat 下载并放入该目录下。

3. 运行切换
右键点击 Switcher.bat，选择 “以管理员身份运行” (由于游戏通常安装在 C 盘，修改配置文件需要权限)。

根据菜单提示输入数字：

输入 1：切换为 官方服 (Official)。

输入 2：切换为 Bilibili服 (B站)。

脚本会自动修改 config.ini 并直接通过 YuanShen.exe 启动游戏。

⚠️ 注意事项
跳过启动器：修改配置后，请直接通过脚本启动或双击 YuanShen.exe。若使用官方 HoYoPlay 启动器，它可能会检测到配置文件差异并尝试修复（重新下载）。

版本更新：当游戏发布大版本更新时，建议先切回官服模式通过官方启动器完成更新，再重新使用脚本切换。

编码格式：编辑本脚本时，请务必使用 ANSI 编码保存，否则中文菜单会出现乱码。
