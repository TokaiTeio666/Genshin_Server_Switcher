# Genshin Impact Server Switcher (原神官B服一键切换器)

这是一个轻量级的 Windows 批处理脚本（.bat），旨在解决《原神》官方服与 Bilibili 服之间切换时需要重复下载庞大资源的问题。

## 📖 背景原理
《原神》不同渠道服的游戏主体资源（模型、地图、音效等）基本一致。本脚本通过修改游戏目录下的 `config.ini` 配置文件，改变客户端的识别标识（Channel），从而实现“一套资源，两个服玩”。

## 🚀 快速上手

### 1. 放置脚本
将生成的 `.bat` 脚本放置在游戏主程序目录下。
> **参考路径**：`...\Genshin Impact Game\` (该目录下应能看到 `YuanShen.exe` 或 `GenshinImpact.exe`)。

### 2. 运行环境
* **权限要求**：由于游戏通常安装在系统盘，修改配置文件需要管理员权限。请 **右键点击脚本 -> 以管理员身份运行**。
* **B服补丁**：如果你的原始文件是官服，切换 B 服时需确保目录下存有 `plugins` 文件夹，否则无法弹出 B 站登录界面。

### 3. 操作步骤
1. 双击运行脚本。
2. 根据菜单提示输入数字：
   - **1**：切换为 **官方服 (天空岛)**。
   - **2**：切换为 **Bilibili 服 (世界树)**。
3. 脚本会自动更新 `config.ini` 并直接通过 `YuanShen.exe` 启动游戏。

## ⚙️ 核心参数对照表
脚本会根据选择自动应用以下 `config.ini` 配置：

| 参数项目 | 官方服 (mihoyo) | Bilibili 服 (bilibili) |
| :--- | :--- | :--- |
| **channel** | 1 | 14 |
| **sub_channel** | 1 | 0 |
| **cps** | mihoyo | bilibili |
